# MDC明細取得の省力化（実験）
基準日: 2026-11-17 JST

## 線引き
* 未確定分は公式WEBで閲覧可能。スマホ版はPDFのみ、PC版はPDF/CSV。締め日15日から請求額確定頃（21日前後）の新規利用は反映が遅れることがある。キャンセルは未確定分に反映されない場合がある。
* 公式案内: https://www.cr.mufg.jp/mufgcard/contact/guide/detail_inquiry/index.html
* JALカード公式入口: https://www.cr.mufg.jp/jalcard/select/index.html
* 利用者規定第7条（本人以外へのID・パスワード・OTPの提供/利用を禁止）: https://www.cr.mufg.jp/member/rule/mufgcard/webservice.html
* 公式個人向け公開APIの仕様は未確認。ログイン後の画面構造、正規ダウンロード方式および自動操作可否は実機未検証。非公開API、認証回避、サーバーでの資格情報保存や無人ログインは採用しない。

## 第一段階（試作済み）
PDFの原本バイトをiPhoneの共有シートからショートカットで渡す。Safariでのファイル保存と再選択を省けるか実機確認する。

ショートカットを端末で作成:
1. 共有シートに表示し、入力をPDFに限定する。
2. 入力PDFをBase64でエンコード（改行なし推奨）。
3. テキスト: HT-MDC-PDF-V1: の直後にBase64の結果を結合。
4. クリップボードにコピー（ローカルのみ、有効期限を短く設定）。
5. 家計アプリを開く。取込 → MDC/JAL PDF明細 → 試験機能 → 貼り付け。
6. 既存の請求額・カード識別・重複・最終確認がそのまま動作することを確認。既存PDFの内容と同一か確認してから登録する。

試作はPDF共有ができることが前提。実機で共有入力が取得できなければ無理に採用しない。クリップボードには一時的に機密なPDFが存在するので、ローカルのみ・短い有効期限を推奨。コピーしたデータをURL、ログ、チャット、外部サービスに渡さない。アプリ側では明示的な貼付イベントだけを受け付け、PDFデータを画面に残さない。

## 第二段階（本命・未実装）
MDC WEB版に本人がSafariでログイン → 未確定明細へ。画面から公式ダウンロードを利用できる導線・ブラウザ内での安全な省力化を確認。本人/家族カードの識別、決済日、請求月、請求総額、全明細・取消等を正本と一致検証する。HTML明細を直接読む方式はこれらの照合ができるまで登録しない。実際のHTMLを外へ送る必要はなく、画面構造の最小限の匿名化サンプルで検討する。

## リリース判断
実験ブランチに留める。実機で操作数の削減、PDF共有可能性、Safari/PWAの入力制約を検証してから本番採用を判断する。正式リリース時にはキャッシュ/JS資産版を更新し、既存PDF取り込み・金額照合・重複排除の回帰テストを行う。
